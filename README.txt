ANIRUDH BHATI — PORTFOLIO

This is a standalone, static HTML portfolio. It does not use the original bundler/runtime, so navigation such as #skills works directly when opened locally and after hosting.

Files:
- index.html — portfolio website
- Anirudh_Bhati_Resume.pdf — resume

For GitHub Pages:
1. Create a new GitHub repository (for example: anirudh-bhati-portfolio).
2. Upload index.html and Anirudh_Bhati_Resume.pdf to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment choose Deploy from a branch.
5. Select the main branch and / (root), then Save.
6. GitHub will give you a public URL.

Use the public URL on Upwork instead of a file:/// URL.
